# 合同会社MKT コーポレートサイト

既存のWixサイト（https://goudoumkt.wixsite.com/mktoita）のリニューアル。
**ブランディングを目的としたコーポレートサイト**として再構築したもの。

- 制作開始: 2026-08-28
- 参考にしたデザイン: [Paint Up Sugar](https://paintupsugar.com/)（構成・モーション設計）
- 既存の[採用特設サイト（STUDIO）](https://mkt-company.studio.site/)は残し、本サイトから導線を張る棲み分け

## 1. ブランド定義（このサイトの設計の芯）

### トーン
**温かみ × 誠実。**
MKTの理念（「人を信じる」「優しさ＝戦略」）を、軽く見えないかたちで表現する。
参考サイトのポップさは *動きの設計* だけを借り、色とタイポは誠実側に寄せている。

### カラーパレット

| 用途 | 変数 | 値 | 意図 |
|:--|:--|:--|:--|
| ベース | `--cream` | `#F7F2E8` | 生成りの紙。白より体温がある |
| ベース（濃） | `--cream-deep` | `#EFE7D8` | セクションの切り替え |
| 面 | `--paper` | `#FFFDF8` | カード・帯 |
| 文字 | `--ink` | `#1C1815` | 黒より柔らかい墨 |
| 主色 | `--indigo` | `#17364A` | 藍＝誠実・early morning。配送の朝 |
| 主色（濃） | `--indigo-deep` | `#0E2434` | 反転セクション |
| 差し色 | `--amber` | `#C86B32` | 琥珀＝人の温度。CTAとアクセントのみに使う |

アクセントは**琥珀1色に限定**している。増やすと途端に安っぽくなるので、色を足したくなったら濃淡で解決すること。

### タイポグラフィ

| 役割 | フォント | ウェイト | 理由 |
|:--|:--|:--|:--|
| 和文（見出し・本文とも） | **Zen Maru Gothic** | 見出し700／本文500 | 参考サイトと同じ丸ゴシック。角のない書体は「人を信じる」という理念と直結する |
| 欧文・数字 | **Jost** | 300–600 | Futura系。参考サイトの `futura-pt`（Adobe Fonts・要ライセンス）に相当するGoogle Fonts無料版 |

参考サイトの指定は `"Zen Maru Gothic", 游ゴシック体, YuGothic, ヒラギノ角ゴ ProN W3, メイリオ` というフォールバック順で、本サイトもこれに合わせている。

丸ゴシックは温かい反面ゆるく見えやすいので、**色（濃紺＋生成り）と余白で誠実さを担保する**という役割分担にしている。書体を硬くする方向では調整しないこと。

### モーション語彙（10種）

**同じ動きを使い回さない**ことがこのサイトの設計方針。要素の性質ごとに動きを変えている。
（1種類のフェードアップを全要素に適用すると、それだけで「自動生成された感じ」になる）

| # | 演出 | 実装 | 使いどころ |
|:--|:--|:--|:--|
| 1 | **mask** | 行を `overflow:hidden` で囲み、中身を `translateY(115%)` から戻す | 見出し。行ごとに遅延をずらす |
| 2 | **up** | 控えめなフェードアップ | 本文のみ。多用しない |
| 3 | **curtain** | `clip-path:inset()` で覆いが下から開く | 写真の登場 |
| 4 | **line** | 罫線が `scaleX` で引かれる | ラベル横の罫 |
| 5 | **roll** | 数字の桁が縦に1回転して着地 | 実績数値 |
| 6 | **parallax** | 進行度に応じて前景/背景に速度差 | ヒーロー・各写真 |
| 7 | **pin** | `position:sticky` でセクションを固定し、進行度でMISSION→VISIONが切り替わる | 理念 |
| 8 | **hscroll** | 縦スクロールを横移動に変換 | グループ事業5枚 |
| 9 | **marquee** | スクロール速度に反応して加速する流れ文字 | セクション間の帯 |
| 10 | **cursor** | 追従カーソル。画像やリンクで拡大しラベルを表示 | PC（`pointer:fine`）のみ |

そのほか：ローダー（0→100%カウント＋5枚パネルが開く）、キービジュアルのクロスフェード＋ケンバーンズ、
大分の現在時刻（JST・実時刻）、ヘッダーの自動格納。

**実装上の注意**
- スクロール連動処理は `initScroll()` 内の**単一のrAFループ**に集約している。処理を足すときもここに入れること（リスナーを増やすとカクつく）
- 横スクロールセクションの高さは**実際の移動距離から逆算**して JS が設定する（`layoutHs()`）。CSSの `height` を直接いじらないこと
- `prefers-reduced-motion: reduce` と JS無効時は、固定・横スクロールを解除して通常の縦積みに落とす（実装済み）

## 2. ページ構成

シングルページ構成。上から:

1. **Hero** — ミッションをそのままキャッチに（信じる力で、人と地域の未来を支える。）
2. **マーキー** — 3つの姿勢を流す
3. **About** — 「運ぶ会社である前に、人を信じる会社でありたい。」
4. **Numbers** — 売上1億円 / 28名 / 6領域 / 5エリア
5. **Business** — 配送3本（宅配便・スポット/チャーター・リネン）を主役として大きく
6. **Group business** — 「人に投資したら、事業が増えた」枠で5事業を横カルーセル
7. **Area** — 大分県／福岡県
8. **Philosophy** — MISSION / VISION / 経営方針4項目（アコーディオン、濃紺反転）
9. **Message** — 代表メッセージ
10. **People** — 共育の3本柱＋採用特設サイトへの導線
11. **Company** — 会社概要
12. **Contact** — 電話＋フォーム

文章は既存の採用特設サイトに掲載されている内容（ミッション・ビジョン・経営方針・代表メッセージ・会社概要）を一次情報として使用。**数字や事実は勝手に足していない。**

## 3. 写真・ロゴの差し替え

### 現在の状態：フリー素材で仮置き中

**いま入っている写真はすべて [Pexels](https://www.pexels.com/) のフリー素材（商用利用可・帰属表示不要）。本番写真に差し替えること。**

意図的に入れていない枠が1つある：

- `message.jpg`（代表 森下富弘）— **ここにフリー素材の人物写真は入れない。**
  「代表 森下富弘」と書かれた場所に別人の顔写真を置くと、閲覧者が本人だと誤解する。実在の人物に関する誤情報になるため、
  本番写真が用意できるまでデザインプレースホルダーのままにしてある。
- `about.jpg` のキャプションは、フリー素材の間だけ場所を特定しない文言（「人を軸にした現場づくり」）にしている。
  本番写真に差し替えたら「大分市三川上・MKT事務所」等の実際の場所名に戻すこと（HTMLにコメントあり）。

### 仕組み
各画像枠は「プレースホルダーSVGを背景に敷き、その上に写真の `<img>` を重ねる」構造。
写真が無ければ `onerror` で `<img>` が消え、プレースホルダーが見える。

**→ `images/` に下記のファイル名で .jpg を置くだけで差し替わる。HTMLの編集は不要。**

### 必要な写真一覧

| ファイル名 | 推奨サイズ | 内容 |

| `hero-01.jpg` | 1600×1000 | KV①：軽バン・配送現場。**最重要** |

撮影が間に合わないものは、プレースホルダーのまま公開しても崩れない。ただし **hero-01 だけは必ず本番写真を入れること**（ここで印象が決まる）。

### ロゴ
`images/logo.svg` は**暫定のマーク**。正式ロゴを同じファイル名で上書きすれば差し替わる。

- 濃い背景（イントロ・ヘッダー未スクロール時・フッター）では自動で白抜きシルエットになる
- 正式ロゴが「マーク＋MKTの文字」一体型の場合、ヘッダーの `MKT` テキストと重複する。その場合は `index.html` の `.l-header__logo-text` の `<strong>MKT</strong>` を削除する

## 4. お問い合わせフォームの送信先設定

現状 `action="#"` のため未送信（送信するとアラートで電話番号を案内する安全装置が入っている）。
公開前に以下のいずれかを設定すること。

**A. Formspree（最短・無料枠あり）**
```
https://formspree.io/ でフォーム作成 → 発行されたURLを index.html の
<form class="contact__form" ... action="#" を action="https://formspree.io/f/xxxxxxx" に変更
```

**B. Googleフォーム連携／WordPress化する場合**は別途相談。

設定後、`index.html` の `.contact__note`（※送信先の設定が必要です…）の一文を削除する。

## 6. 公開：GitHub Pages（確認用）

### リポジトリ構成の注意

このディレクトリは **`ai-management` とは別の独立したGitリポジトリ**。

- 公開リポジトリ: `uak1125-art/mkt-corporate-site`
- 親の `ai-management` はプライベート（経営コンテキスト・顧客情報を含むため公開不可）。GitHub Pagesは無料プランだとプライベートリポジトリから公開できないので分離した
- そのため `ai-management` 側の `.gitignore` でこのディレクトリを除外している
- **このフォルダ内でのgit操作は、すべてこのサイト専用リポジトリに対して行われる**

### 現在の状態：確認用公開

検索エンジンに拾われないよう2重にブロックしてある。

- `index.html` の `<meta name="robots" content="noindex, nofollow">`
- `robots.txt` の `Disallow: /`

（GitHub PagesはHTTPレスポンスヘッダーを設定できないため、Cloudflare Pages用の `_headers` は使えない）

### 更新をサイトに反映する

このディレクトリで:

```bash
git add -A && git commit -m "update: 内容の説明" && git push
```

pushの1〜2分後に自動で反映される。公開URL: **https://uak1125-art.github.io/mkt-corporate-site/**

### 本番公開への昇格手順

確認用 → 本番に切り替えるときは、以下を**必ずセットで**行う。

1. `index.html` の `<meta name="robots" ...>` の行を削除
2. `robots.txt` を本番用（`Allow: /`）に書き換え
3. `index.html` の `og:image` を絶対URLに変更（SNSシェア時のサムネイル用）
4. フォームの送信先を設定（→ 4章）
5. 独自ドメインを取得し、リポジトリの Settings → Pages → Custom domain に設定＋DNSにCNAME
6. コミット＆プッシュ

**独自ドメインの取得方針（例：`mkt-oita.jp`）は未決定。** ここは要相談。
